react/jsx-key is off because of one specific pattern, not because keys do not
matter. Detail panels pass label/value pairs to <KeyValue items={[['Status',
<StatusBadge/>], ...]} />, and the rule flags any JSX inside an array literal.
KeyValue keys every row itself (<React.Fragment key={label}>) and renders each
value as a single child of a <dd>, never as an array, so React needs no key on
the value — adding one would be cargo cult. Every real .map() that renders a
list does carry a key, and the browser suite fails on console errors, which is
what would catch a genuinely missing one.
